SESAAT APPS v1.3.0 (PRODUCTION RELEASE)

Segari Daily Worker Salary & SKU Tracker

Solusi cerdas bagi rekan kerja harian Segari untuk menghitung upah shift secara akurat, kustomisasi skin maskot, visualisasi jadwal sesuai warna Excel Segari, memantau target komisi SKU Severity 1-3, mencetak slip gaji PDF, dan integrasi WhatsApp.

Download APK Langsung
Versi Resmi v1.3.0 • Android 6.0+
Ukuran: 20.2 MB • Bebas Iklan • In-App OTA Update
FITUR UNGGULAN v1.3.0

Semua Kebutuhan Kerja dalam Satu Aplikasi

4 Maskot Segari Presisi (Build 5)

Pilihan maskot berburu sembako & buah segar: Ular Hijau 🐍, Ulat Sayur 🐛, Kucing Gudang 🐱 (1 Kotak), dan Ayam Peternak 🐔 (1 Kotak)!

Skema Warna Shift Excel Segari

Visualisasi kalender presisi 100% mengikuti spreadsheet jadwal Segari: 🔴 Merah (OFF), 🟣 Ungu (MP3H), 🟠 Oranye (Siang), 🟡 Kuning (Subuh), 🔷 Cyan (Pagi).

Target SKU Multi-Tier & Edit Komisi

Mendukung 3 tier pencapaian: Severity 1 (13.500 SKU / Rp 400rb), Severity 2 (15.500 SKU / Rp 500rb), dan Severity 3 (17.500 SKU / Rp 600rb) dengan fitur edit fleksibel.

Input Jam Kerja Dial & Preset

Putar jarum jam interaktif untuk memilih jam masuk & pulang, atau gunakan preset 1-klik untuk shift Reguler, MP3H, dan lembur Segari.

Aturan Lembur & Double MP3H

Kombinasi fleksibel: Shift Reguler + Lembur 1x MP3H (11 Jam / Rp 170.000) atau Double MP3H (6 Jam / Rp 100.000) sesuai standar operasional Segari.

Cetak Slip Gaji PDF & WhatsApp

Ekspor slip gaji resmi berformat PDF dan format pesan WhatsApp rapi dengan rincian kehadiran harian, komisi SKU, potongan denda QC, dan tanggal gajian.

Cara Memasang Aplikasi di HP Android:

  1. Klik tombol hijau "Download APK Langsung" di atas.
  2. Setelah file SegariSalaryTracker-v1.3.0.apk selesai diunduh, buka file tersebut di HP Anda.
  3. Jika muncul peringatan "Izinkan instalasi dari sumber ini", aktifkan izin pada pengaturan browser HP Anda.
  4. Pilih "Install / Update". Aplikasi langsung siap digunakan!
  5. Catatan: Jika Anda sudah menginstal versi sebelumnya, aplikasi akan langsung diperbarui tanpa menghapus data absensi lama Anda.
